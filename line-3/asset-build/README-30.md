# Arriving Share image assembly

The installed image tool edited the inherited wall to add a charcoal basket and ochre pebbles. `finish-30.cjs` transfers only selected pigment inside a bounded silhouette onto the original stone, retaining every pixel outside its 121 × 88 patch. It reuses the existing standard-library Node PNG codec and licensed JPEG encoder; no installed dependency is needed.

This was a one-shot operation on the generated input at `artifacts/line-3/wall-v13.png`, now replaced by the completed wall. The script checks both input hashes and refuses to run on that completed output. The generated intermediate was not retained. `preservation-30.json` records the computation; `../step-30-review.json` records dimensions, format, visual inspection and limitations. Only final images are retained. The canonical link points to wall-v13.png; old walls and records are unchanged.
